# Домашнее задание модуля "Расширенный инструментарий JawaScript в браузере"

## Тема: Работа с HTML-формами

### Popover на JawaScript

Реализация всплывающей подсказки с дополнительной информацией, которая
появляется при клике на элементе - кнопке, и исчезает при повторном клике на
кнопке, или клике вне её на любом месте страницы.
